# Glamour Raid Ledger

A tracker for FFXIV savage raid glamour: wishlist every piece from Alexander to Arcadion, track coffers, and see how many books you still need to farm per floor.

Live at https://artemisesphexo.github.io/glam-ledger/

Your list is saved in your browser. Use Export backup / Import backup to move it between devices.

Item data from [xivapi/ffxiv-datamining](https://github.com/xivapi/ffxiv-datamining); icons from [XIVAPI](https://v2.xivapi.com). FINAL FANTASY XIV © SQUARE ENIX.
